# Feature Guide

## Dashboard

Shows estimated total units, available lots, estimated bulk value, media work, category readiness, lot status mix, recent lots, and recommended next action.

## Categories

Lists current categories with measurement method, location, estimated units, default lot size, and available full-lot estimate. New categories can be created from a modal form.

## Measure and Estimate

Choose a stack-based category, calibrate a test stack, enter total thickness and print dimensions, and define one lot. Results update instantly and can be saved back to the category.

## Category Variables

Choose an object category and control its fields without changing component code. Variables can be added, reordered, deleted, marked required, assigned allowed values, attached to pricing modifiers, and included or excluded from buyer copy, lot cards, and description templates.

## Object Inventory

Choose Frames, Framed Printed Art, Original Art, Framed Mirrors, Frameless Mirrors, or Framing Material. The form renders the category's variables, calculates area, perimeter, size class, modifier breakdown, rounded price suggestions, safe buyer copy, and review warnings. Saved objects can be searched, filtered, edited, and deleted.

## Build Lots

Choose a category and pricing tier. Print categories subtract units already allocated to active lots and limit the number of full lots. Object categories require exact-piece selection and recommend a lot price from the selected items' calculated value. Generated lots receive category, quantity, curation, sequence, status, price, creation metadata, pickup rule, and object IDs when applicable.

## Lot Card

Displays lot ID, status, category, curation, approximate quantity, stack height when relevant, condition, buyer types, location, price, unit price, and pickup controls. Browser print rules isolate the card.

## Media Planner

Print lots receive the standard eight-shot plan. Object lots receive front, back, corner, frame-detail, damage, scale, group, lot-card, and location shots; mirrors add surface and hardware shots, while original art adds signature and label shots. Completion is tracked per filename.

## Pricing Tiers

Edit tier name, quantity, and price. Unit price is derived immediately. New tiers can be added per category.

## Search and Notifications

Search matches category names, codes, locations, individual object records, variable values, and lot IDs. Object results open the correct category register. Notifications summarize media and pickup work.

## Export Center

- CSV: flat lot register
- JSON: complete local data backup
- Print: current browser print dialog
- Reset: restore original seed data after confirmation

## Foundation modules

Buyer CRM, Sales Tracker, and the dedicated Media Planner currently display their planned scope. Their underlying fields and business rules are documented for the next implementation phase.
